## What's Changed

### ✨ First release
- Live vacuum dial under Tools → Vacuum Gauge
- Optional mini gauge that floats on the main screen, in five styles: Number, Dial, Bar, Slim, Colour block
- Check while a job runs: show a warning, or feed hold with a warning
- Firmware for the M5Stack ATOM Lite with the Tube / Air Pressure Unit

### 📦 Install
Download `community.vacuum-gauge_v1.1.1.zip` below. In ncSender open Plugins → Install from a ZIP file. Do not unzip it.

Needs ncSender 2.0.225 or newer.
